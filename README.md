# دیجی پرینت | Digi Print

نسخه اول فروشگاه اینترنتی «دیجی پرینت» برای فروش کارتریج پرینتر.

## فایل‌ها
- `index.html` — ساختار صفحه
- `style.css` — طراحی و ظاهر سایت
- `app.js` — محصولات، فیلتر برند و سبد خرید
- `README.md` — راهنمای پروژه

## اجرا
فایل `index.html` را با Chrome یا Edge باز کنید.

## انتشار با GitHub Pages
1. در GitHub یک Repository بسازید.
2. این چهار فایل را داخل Repository آپلود کنید.
3. از مسیر **Settings → Pages** گزینه انتشار از Branch اصلی را فعال کنید.
4. چند لحظه بعد لینک سایت ساخته می‌شود.

## نکته
قیمت‌ها و شماره تماس نمونه هستند و قبل از انتشار نهایی باید با اطلاعات واقعی فروشگاه جایگزین شوند.
برای پرداخت آنلاین، پنل مدیریت، ثبت سفارش و درگاه بانکی باید بخش Backend/Database و درگاه پرداخت به پروژه اضافه شود.
